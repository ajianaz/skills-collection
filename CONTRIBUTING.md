# 🤝 Contributing to AI Skills Collection

## Community First Statement

We believe in the power of community collaboration to build exceptional AI skills. This project thrives on contributions from developers, designers, and AI enthusiasts like you. Whether you're fixing a bug, adding a new skill, improving documentation, or sharing ideas, your contribution is valuable and deeply appreciated.

**Our community is built on respect, inclusivity, and the shared goal of creating powerful AI skills that transform how we work with technology.**

## 🚀 How to Contribute

### Reporting Issues

Found a bug or have a suggestion? We'd love to hear from you!

1. **Check existing issues** to avoid duplicates
2. **Use clear, descriptive titles** for your issue
3. **Provide detailed information**:
   - Steps to reproduce the issue
   - Expected vs. actual behavior
   - Environment details (OS, AI assistant used, etc.)
   - Screenshots if applicable

### Submitting Pull Requests

We welcome pull requests that improve the project!

1. **Fork the repository** and create a new branch for your feature
2. **Follow the existing code style** and structure
3. **Ensure all tests pass** (if applicable)
4. **Update documentation** as needed
5. **Submit a clear pull request** with:
   - Descriptive title
   - Summary of changes
   - Reference to related issues (if any)

### Adding New Skills

Skills are the heart of this project! Follow these guidelines:

1. **Use the standard skill structure**:
   ```
   skill-name/
   ├── SKILL.md              # Core instructions & workflows
   ├── references/           # Detailed docs & patterns
   ├── scripts/              # Automation utilities
   └── assets/               # Templates & resources
   ```

2. **Keep SKILL.md concise** (under 500 lines) with:
   - Clear purpose description
   - Step-by-step workflows
   - Practical examples with actual file paths
   - Installation instructions (if needed)

3. **Test your skill** with real-world scenarios before submitting

4. **Include appropriate licensing** information in your skill

### Improving Documentation

Good documentation is crucial for community adoption:

1. **Fix typos and grammatical errors**
2. **Clarify ambiguous instructions**
3. **Add missing examples or use cases**
4. **Update outdated information**
5. **Translate documentation** (if you know multiple languages)

## 📋 Contribution Guidelines

### Code Style Expectations

1. **Follow existing formatting patterns** in the project
2. **Use clear, descriptive names** for files and sections
3. **Write in markdown** with proper formatting
4. **Keep line length reasonable** (around 80-100 characters)
5. **Use consistent heading levels** throughout documents

### Testing Requirements

1. **Validate all examples** in your contribution
2. **Test skills with different AI assistants** if possible
3. **Ensure all links work** and are relevant
4. **Verify that instructions** are complete and accurate

### Documentation Requirements

1. **Document new features** thoroughly
2. **Include examples** that demonstrate real-world usage
3. **Explain complex concepts** in simple terms
4. **Maintain consistent tone** and style with existing documentation
5. **Update table of contents** if adding new sections

## 💬 Communication Channels

### Asking Questions

- **GitHub Issues**: For bug reports and feature requests
- **GitHub Discussions**: For general questions and ideas
- **Pull Request Reviews**: For code-specific discussions

### Discussing Ideas

We welcome ideas for new skills and improvements:

1. **Start with a GitHub Discussion** to gauge community interest
2. **Outline your idea** with use cases and potential implementation
3. **Consider existing skills** to avoid duplication
4. **Be open to feedback** and collaboration
